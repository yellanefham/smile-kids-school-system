## 🌟 أبرز مميزات النظام

### 1️⃣ نظام رصد الدرجات والتقييمات
- رصد درجات الاختبارات الشهرية (شهر 1، شهر 2) واختبار نهاية الترم الأول والثاني.
- حساب التقديرات والنسب المئوية آلياً (ممتاز، جيد جداً، جيد، مقبول).
- نموذج المعلم الإلكتروني السريع لإدخال درجات الفصل بضغطة زر.
- تصدير شيتات الدرجات الشاملة لكافة المواد والمراحل.

### 2️⃣ كشوف الحضور والغياب والشيت اليدوي
- تسجيل الحضور والغياب اليومي بنقرة زر (حاضر، غائب، متأخر، معذور).
- توليد شيت حضور يدوي عريض (Manual Wide Attendance Sheet) يغطي كافة أيام الشهر والترم مع مفاتيح الرموز الرسمية.
- إحصائيات ونسب مئوية فورية للانتظام والانضباط المدرسي.

### 3️⃣ شهادات التقدير والتفوق الأكاديمي
- توليد شهادات تفوق رسمية ومميزة مع ختم المدرسة الذهبي وتوقيع شؤون الطلاب ومديرة المدرسة.
- دعم اللغتين (عربي لقسم العربي، وإنجليزي لقسم اللغات).
- طباعة فردية لكل طالب أو طباعة مجمعة لكافة طلاب الفصل دفعة واحدة.

### 4️⃣ لوحة كشوف الطلاب وكروت الواتساب (Roster Dashboard)
- استعراض قوائم 131 طالب وطالبة موزعون على 9 صفوف دراسية (من الصف الأول الابتدائي حتى الثالث الإعدادي).
- عرض مقارن متجاور (قسم العربي وقسم اللغات جنباً إلى جنب).
- توليد نصوص واتساب منسقة وجاهزة للنسخ بضغطة زر.
- مجلد خاص بالصور عالية الدقة (3200 × 2000 بكسل) المجهزة للإرسال المباشر لمديرة المدرسة عبر واتساب.

## 💻 التقنيات المستخدمة
- **HTML5 & CSS3** مع دعم كامل للكتابة والاتجاه من اليمين لليسار (`dir="rtl"`).
- **Tailwind CSS** للتصميم العصري المتجاوب مع كافة الشاشات وأجهزة الموبايل والتابلت.
- **Modern JavaScript (ES6+)** لمعالجة البيانات والتصفية والتخزين المحلي `localStorage`.
- **خطوط جوجل:** Cairo و Tajawal.
